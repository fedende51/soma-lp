# SOMA Scheduler film language

Emotional target: calm control under change. Motion personality: Premium. Each scene has one dominant action, with staggered supporting movement and a small motivated camera drift during reading holds.

Six base colors: navy #003c5b, blue #0b79a9, cyan #00b9c1, pale turquoise #61dedb, cool white #fbfcfc, slate #526b79. Tint surfaces are these colors composited over white. Cyan is a signal/rule, not small text on white. Body text is navy or slate; inverse text is white. Only the original logo carries its supplied continuous spectrum.

Display: local IBM Plex Sans Medium. Interface: local Manrope. Short sentence case headings; large numerals only for example order data, never invented proof metrics. Grid labels are supporting metadata, not reading requirements.

Hero continuity: a blue operation surface changes width, height and radius, becoming a slip, timeline operation, review surface, route and final brand plate. Child text leaves before new text arrives. The carried operation uses identical coordinates at each handoff.

Timing: 120 BPM / half-second grid. Quick 120ms, standard 350ms, deliberate 600ms. Critically damped closed-form step response for camera/type. Slight overdamped drag release, no elastic bounce. Primary movement precedes secondary movement by 60–100ms. Large motion uses anticipation and a tapered motion echo during the fast interval. No decorative particles, glow or generic gradient background.

Landscape safe area: 96px horizontal, 70px vertical. Portrait: 72px horizontal, 250px top, 320px bottom. Critical titles and CTA stay within these bounds. Portrait layouts stack headings and board rows; all board columns are independently mapped to the available width.

Source logos: assets/logo_soma_light.png and assets/logo_soma_dark.png. Crop viewBoxes from the existing approved asset metadata, never retype SOMA as its wordmark. Real pixel lettering is retained.

Sound: original composition with piano-like struck strings, bowed harmonic bed and restrained acoustic-style percussion. A musical arc, not a repeating arpeggio. Effects correspond to visible presses, releases and content handoffs. Full mix target −14 LUFS / true peak at most −1 dBTP. Music-only MP4s omit UI effects.
